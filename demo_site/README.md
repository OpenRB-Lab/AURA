# AURA demo site

Static demo page (audio players). Open `index.html` locally, or deploy on GitHub Pages:

1. Commit this `demo_site/` folder to a repo.
2. Repo Settings -> Pages -> set the source to this folder (or copy it to `docs/` on `main`, or push to a `gh-pages` branch).
3. All asset paths are relative, so it works at `https://<user>.github.io/<repo>/`.

`.nojekyll` is included so the `audio/` folder is served untouched.
